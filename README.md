
# Retail Sales & Inventory Management System

## Project Overview

This project demonstrates the practical application of SQL, Excel and Power BI for inventory management, product analysis and supplier management.

## Developed By

- Name: Tejaswini Bulbule
- Qualification: MCA
- Institute: TechnoSignia Software Training Institute
- Project: Data Analytics and Data Science Internship

## Business Problem

Businesses need an effective inventory management system to monitor product availability, manage suppliers, analyze stock quantities and support inventory-related decisions.

## Project Objectives

- Manage product and supplier information.
- Monitor available inventory.
- Analyze product purchase prices.
- Identify low-stock products.
- Establish relationships between database tables.
- Develop an interactive Power BI dashboard.
- Support data-driven business decisions.
